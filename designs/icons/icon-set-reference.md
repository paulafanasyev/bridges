## Design Notes for Icons
1. **Platform Icons**: Use SVG sprites for all interface icons to ensure crisp rendering at any size.
2. **Emoji Fallback**: On mobile, system emoji can be used for hobby tags and zodiac signs.
3. **Tab Bar Icons**: 24×24px for mobile, 20×20px for desktop.
4. **Action Buttons**: 28×28px for standard, 32×32px for primary actions.
5. **Cultural Balance**: Every icon set includes both Chinese and Russian cultural references.
6. **Color**: Icons inherit color from parent text by default. Use `currentColor` in SVG fills.
